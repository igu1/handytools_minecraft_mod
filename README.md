# Handy Tools

Small punchy tools: path roller, redstone signal meter and a filtered hopper.

> Scaffolded from the `orebushes` NeoForge 1.21.1 + Stonecutter template.
> Logic first; textures/models/lang to be added last.

## Build
```bash
./gradlew build            # compile + jar
./gradlew runClient        # launch the dev client
./gradlew buildAndCollect  # copy jar into builds/1.21.1-neoforge/
```
