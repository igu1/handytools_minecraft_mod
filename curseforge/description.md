# Handy Tools

**Little tools, big time savers.**

**Released — version 1.0.0+26.1.2.**

Three practical tools: roll out dirt paths in a plane, read any redstone signal, and a hopper that only accepts the item type you choose.

## Features

### Path Roller
Right-click solid ground to lay a flat plane of dirt paths in one go. Width and depth are configurable.

### Signal Meter
Right-click any block to read the redstone signal it receives and emits, and whether it is powered.

### Filter Hopper
A hopper that only accepts one item type. Right-click with an item to set the filter, sneak + right-click to clear it, and right-click empty-handed to open it.

## Configuration

Each tool has an enable toggle, and the Path Roller has width and depth settings, in the common config (config/handytools-common.toml) or the in-game mod settings.

## Requirements

- **Minecraft 26.1.2**
- **NeoForge 26.1.2.108 or newer**
- **Java 25** (bundled with Minecraft 26.1)
- Works in single-player and on servers.

## Installation

1. Install **NeoForge** for Minecraft 26.1.2.
2. Drop the `.jar` into your `mods/` folder.
3. Launch the game. That is it — no dependencies and no configuration required to start.

## Compatibility

- Works in single-player and on any server (client-side where noted).
- Should be compatible with most other mods. Please report conflicts in the issue tracker.
