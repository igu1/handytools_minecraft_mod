# Changelog

## 1.0.0 — Minecraft 26.1.2

First release.

- Added **Path Roller** — Right-click solid ground to lay a flat plane of dirt paths in one go. Width and depth are configurable.
- Added **Signal Meter** — Right-click any block to read the redstone signal it receives and emits, and whether it is powered.
- Added **Filter Hopper** — A hopper that only accepts one item type. Right-click with an item to set the filter, sneak + right-click to clear it, and right-click empty-handed to open it.
- Shared HUD design system for consistent panels across every module.
- In-game configuration screen with full English localisation.
- 30 automated calculation regression checks.
